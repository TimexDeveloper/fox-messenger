## 🎯 Как это Работает

### Автоматическое Определение Режима
```
Firebase настроен?
├─ ДА  → Использовать Firebase
└─ НЕТ → Использовать Demo Режим (localStorage)

И всё работает автоматически! ✨
```

### Процесс Входа/Регистрации
```
1. Пользователь на /auth
2. Заполняет email/пароль
3. Система проверяет Firebase
   ├─ Есть → Аутентификация через Firebase
   └─ Нет → Создаёт demo пользователя
4. Сохраняет в localStorage + auth store
5. Редирект на /chats
6. Вход выполнен! ✅
```
